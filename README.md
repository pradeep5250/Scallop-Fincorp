## 📌 Overview

**Scallop Fincorp** is a digital platform designed for credit advisory, microfinance loan processing, group finance management, and institutional debt solutions. It features tailored loan enquiry forms, business loan portals, and an interactive customer onboarding pipeline.

---

## ✨ Features

- **📊 Financial Services Suite:** Dedicated workflows for Business Loans, Group Finance, Personal Credit, and Collateral Advisory.
- **📝 Online Lead Capture:** Dynamic multi-step inquiry forms for prospective borrowers.
- **📱 Responsive Fintech Interface:** Clean, mobile-friendly design using modern UI principles.
- **⚡ Fast Static Architecture:** Lightweight, zero-dependency frontend optimized for fast loading across 3G/4G connections.

---

## 🚀 Local Deployment

Open `index.html` directly in your browser or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
